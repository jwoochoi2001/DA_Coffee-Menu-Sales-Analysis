# 빅카인즈(BIGKinds) 수집 계획 — 신메뉴 출시 X변수

목표: 브랜드 × 기간별 "신메뉴 출시" 관련 기사 수 → 출시·화제성 강도 프록시

## 0. 준비
- https://www.bigkinds.or.kr 회원가입 (무료, 신청 절차 없음)
- 로그인 후 상단 **[뉴스 검색·분석]**

## 1. 공통 설정 (모든 검색 동일)
- **기간**: 2016-01-01 ~ 2025-06-30
- **언론사**: 전체 (또는 전국일간지 + 경제일간지 + 인터넷신문 전체 선택)
- **통합 분류 / 사건사고 분류**: 제한 없음
- 검색 후 → **[분석 결과 및 시각화]** → **[기간별 뉴스 추이]** → 단위 **월(月)** → 우측 **다운로드 아이콘 → 데이터(Excel)**

## 2. 브랜드별 검색어 (그대로 복사해서 검색창에)

| 파일명 | 검색어 |
|---|---|
| bk_스타벅스 | `스타벅스 신메뉴` |
| bk_투썸 | `(투썸플레이스 OR 투썸) 신메뉴` |
| bk_이디야 | `(이디야커피 OR 이디야) 신메뉴` |
| bk_할리스 | `(할리스커피 OR 할리스) 신메뉴` |
| bk_메가 | `(메가커피 OR 메가엠지씨커피 OR 메가MGC) 신메뉴` |
| bk_컴포즈 | `컴포즈커피 신메뉴` |
| bk_빽다방 | `빽다방 신메뉴` |
| bk_파스쿠찌 | `파스쿠찌 신메뉴` |
| bk_엔제리너스 | `엔제리너스 신메뉴` |
| bk_폴바셋 | `(폴바셋 OR "폴 바셋") 신메뉴` |
| bk_커피빈 | `(커피빈 OR 커피빈코리아) 신메뉴` |
| bk_탐앤탐스 | `탐앤탐스 신메뉴` |

→ 12개 파일. 각 파일 = 월별 (날짜, 기사건수) 2줄 컬럼.

## 3. (선택) 보조 지표
같은 검색어에서 `신메뉴` 대신 `(신메뉴 OR 시즌음료 OR "시즌 음료" OR 한정판)` 로 한 번 더 → `bk_<brand>_wide` 로 저장.

## 4. (더 간단한 대안 — 트렌드 다운로드가 막힐 때)
검색 후 결과 페이지 상단의 **총 기사 건수**만, 기간을 연도별로 8번 바꿔가며(2017…2024) 적어서 표로:
| 브랜드 | 2017 | 2018 | … | 2024 |

## 5. 보낸 뒤
`scripts/13_ingest_bigkinds.py` 가 파일들을 읽어 브랜드×분기 패널로 만들고
`data/franchise/coffee_brand_panel.csv` (공정위 Y) 와 조인 → `data/franchise/brand_panel_XY.csv`
